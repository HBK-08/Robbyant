# 2026 蚂蚁灵波 VLA 挑战赛执行计划

目标是争取入围决赛。以官方 LingBot-VLA 2.0 训练入口和 FSDP2 全参数微调建立 50 任务基线，随后根据机器人闭环成功率开展最多三轮针对性调优。项目代码固定于 `be969b8fd117fb70550c5d4bf4bc328211b5b1b6`，RoboTwin 固定于 `13c3c47ff4312dd62484bcd51be034af55c062d1`。

## 比赛输入与评测

训练从比赛指定的 `robbyant/lingbot-vla-v2-6b` 预训练权重出发，使用 Aloha-AgileX 的 50 个任务，每任务 50 条 clean 轨迹，共 2500 条。训练数据清单不得包含 randomized 轨迹。已有 `lingbot-vla-v2-6b-robotwin` 用于仿真与推理基础设施检查。

正式评测覆盖 50 个任务的 clean 和 randomized 设置，每任务每设置 100 次，共 10000 次执行。沿用已验证的 FP32 推理；评测种子、结果 JSON 结构和补充要求以官方模板及最新细则为准。

官方赛题与提交要求：<https://tianchi.aliyun.com/competition/entrance/532514/information>。初赛截止为 2026 年 10 月 26 日 24:00，时间按 Asia/Shanghai。

## 资源安排

GPU 0 至 5 每天可使用 24 小时，GPU 6 和 7 禁止使用。六张可用卡每张约 48 GiB 显存。GPU 0 至 3 位于同一 NUMA 节点，GPU 4 至 5 位于另一节点。主线先测试六卡 FSDP2，再根据四卡训练的显存、吞吐和反馈速度评估四卡训练加两卡评测。

正式评测先使用每卡一个推理服务和仿真实例。现有单实例 FP32 实测约占 30.5 GiB。训练、评测、缓存和日志均限制在项目工作区，不修改 Conda base，不影响其他进程。

## 训练配置和调优顺序

优先保留官方模型结构、训练入口、主要损失和精度配置。使用独立 YAML 配置适配六卡 FSDP2，先从每卡 micro batch 1、梯度检查点、完整分片开始；六卡梯度累积 8 次对应有效 batch 48。这些是初始测试参数，不代表已测得的显存或吞吐。

官方 RoboTwin 配置包含深度和视频蒸馏，需要准备 MoGe、LingBot-Depth、DINO-VIDEO 教师权重及配置；按 README 准备 Qwen3-VL 权重与处理器。不能把关闭蒸馏后的配置称为完整官方训练基线。

调优依次考虑学习率与训练时长、任务采样与官方已有冻结范围、规则允许的数据增强或推理参数。每轮尽量只改变一个主要因素。全参数训练遇到持续显存或性能问题时，先检查官方配置，再评估动作专家训练；LoRA 暂不进入主线。
